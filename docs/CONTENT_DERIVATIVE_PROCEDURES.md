# 파생 콘텐츠 절차 우선순위

파생 콘텐츠 생성은 OS 지식창고의 `canonical` 채널 절차를 가장 먼저 사용한다.

정확한 파일명은 `숏폼_만드는_절차.md`, `쓰레드_쓰는_절차.md`, `SEO칼럼_만드는_절차.md`, `인스타_카드뉴스_만드는_절차.md`, `에세이_절차.md`다. 저장된 정본이 없거나 아직 검토 상태이면 `channel-procedures-v1` 기본 절차를 사용해 생성 흐름이 409로 중단되지 않게 한다.

기본 절차는 원문 밖의 사실을 만들지 않고 외부 게시·예약·렌더링을 실행하지 않는 최소 안전 규칙이다. OS에 같은 채널의 정본이 승인되면 다음 생성부터 저장된 정본이 자동으로 우선하며, 기본 절차는 사용되지 않는다.
