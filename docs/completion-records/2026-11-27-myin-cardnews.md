# MYIN 정본 기반 카드뉴스 제작 · 2026-11-27

요청 주제로 정본 원문을 읽고 8장 카드뉴스를 기획·제작했다. 제공된 캐릭터 원본과 공식 공개 보고서 견본을 사용했고, 업무 소품 일러스트는 실제 이미지 생성 도구로 제작했다. 정본 확인 → 장별 원고 → 디자인·그림 → PNG·ZIP으로 이어지는 제작 화면을 기존 OS에 추가했다.

## 반영한 기준

- 회사 카드뉴스 정본: 묶음 v0.3, 문서 v3 저장 후 재열람 확인. 기존 초안 상태는 유지.
- 회사 카드뉴스 디자인 정본: 문서 v2 저장 후 재열람 확인. 기존 원문을 보존하고 신규 MYIN 선택 디자인의 우선 적용 규칙을 추가.
- 핵심 컨텍스트, 원고 말투 정본, 캐릭터 정본 원문을 확인. 실제 사례·개인 진단 결과는 만들지 않았다.
- 문서 편집 중 제목에 잘못 들어간 이번 입력만 원문과 대조해 수정했다. 원문 전체와 추가 기준 완전성을 확인한 뒤 저장했다. 초기 새로고침·실행 취소는 자동 검토가 차단했으므로 실행하지 않았고, 확인된 문단을 직접 고치는 방식으로 복구했다.

- 기존 카드 제작 시작·제작 화면에 새 흐름 진입 링크와 디자인 선택 추가.
- 회사 AI 작업은 MYIN 디자인 선택 시 브랜드·디자인·캐릭터 정본을 추가로 읽고 문서 버전을 기록. 장별 원고 재생성에도 정본 원문을 전달.
- 원고·그림의 기기 저장, JSON 백업·복원, 글자 수 검사, 수정 후 오래된 출력본 차단, 실패 시 재시도.
- 그림 생성 요청문 제공, 실제 생성 그림 업로드, 정확한 문자를 따로 조판하는 PNG 출력. 준비한 예시와 회사 AI API 실행을 구분.
- 미리보기 출력 API: 운영에서는 인증 필요. 로컬 개발 데모만 예외. 외부 이미지 URL·임의 저장 경로 차단, 입력 크기·PNG 해상도 제한.
