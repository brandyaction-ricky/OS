# 광고 디자인 선택 사용성 개선

## 요청과 범위

사용자가 표시한 이미지 광고의 ‘포맷 창고’는 사용 목적과 다음 행동을 이해하기 어려웠다. 작업 선택 영역은 입력란과 버튼의 정렬을 맞춰달라는 요청이 있었다. 이번 작업은 디자인을 고르는 동작과 새 작업·광고 내용 입력의 연결, 작업 선택 행 정렬에 한정한다.

완료 기준은 디자인 선택 버튼을 펼치지 않고 찾을 수 있고, 선택을 확인·해제하고 다음 입력으로 이동할 수 있으며, 새 작업을 만들 때 먼저 고른 디자인이 유지되는 것이다. 생성·승인·다운로드 계약, 상품 정본, 카드뉴스 구현은 변경하지 않는다.

## 구현

- ‘포맷 창고’를 ‘광고 디자인 고르기’로 표시하고 디자인 선택 → 상품·고객 정보 → 사진·문구 준비 순서를 안내했다.
- 디자인마다 미리보기와 선택 버튼을 항상 표시한다. 구성·교체할 요소와 출처는 별도로 펼쳐 확인한다.
- 선택한 디자인 개수·이름·개별 제거·전체 해제·다음 행동을 하단에 묶었다. 선택 중에는 이 영역이 화면 하단에 유지된다.
- 작업 전에도 디자인을 고를 수 있다. ‘이 디자인으로 작업 시작’은 새 작업 이름으로 이동하고, 생성 성공 후 선택을 유지한 채 광고 내용으로 이동한다. 생성 자체를 자동 실행하지 않는다.
- 여러 디자인 선택은 기존의 동일 사진·소구·문구 비교 설정과 후보 수에 연결한다. 승인 전 유료 생성은 계속 막힌다.
- 기존 작업과 새 작업을 같은 3열 구조(항목·입력·버튼)에 배치했다. 입력과 버튼은 모두 44px이며 같은 열에 정렬된다. 좁은 화면에서는 세로로 배치한다.
- 기존 작업은 드롭다운 선택 후 ‘작업 열기’를 눌러 불러온다. 현재 열려 있는 작업명을 별도로 표시한다.
- 변경된 선택 흐름에 맞춰 기존 E2E 검사 4개 파일의 동작과 접근성 이름을 수정했다.

실제 사용자가 참여한 리서치가 아니라 사용자 과제를 따른 작업자의 수동 QA다. 만든 로컬 QA 작업은 휴지통으로 이동했다. 실제 AI 호출과 운영 데이터 변경은 하지 않았다.

자동 브라우저 검사는 앞선 실행에서 Chromium을 시작할 때 macOS 프로세스 권한 제한으로 차단됐다. 이번에는 기존 E2E 파일을 현재 UI에 맞게 유지하고 실제 사용 중인 브라우저에서 위 흐름을 검증했다. E2E 전체 자동 통과를 주장하지 않는다. 승인 전 디자인 선택은 현재 화면의 편집 상태이며 새로고침 복원은 별도 범위다.
