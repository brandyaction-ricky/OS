# 이미지 광고 화면 정돈과 사용 시나리오 QA

## 범위와 완료 기준

사용자가 `/content/images`에 표시한 상품 요약, 작업 선택, 포맷 창고의 가독성을 개선한다. 화면의 제목·입력·보조 설명·버튼 위계를 정리하고 데스크톱과 모바일에서 실제 조작으로 확인한다. 앞서 요청한 광고 소재 제작 QA의 미해결 사항도 함께 기록한다.

이번 검증은 작업자가 사용자 과제를 따라 수행한 QA이며, 실제 고객을 모집한 사용성 조사는 아니다. 로컬 체험 모드에서 진행했고 운영 데이터와 유료 AI 호출은 사용하지 않았다.

## 반영한 변경

| 영역 | 변경 | 사용자에게 달라지는 점 |
| --- | --- | --- |

| 작업 선택 | 이어서 작업하기와 새 광고 시작하기를 별도 영역으로 구분 | 저장된 작업 유무와 다음 행동이 명확해진다. 이름이 비어 있으면 생성 버튼을 비활성화한다. |
| 포맷 창고 | 미리보기 카드, 분류, 선택 상태, 펼침 설명 | 포맷 이름을 하나씩 열기 전에 디자인을 비교할 수 있다. |
| 포맷 검색 | 검색·분류 입력을 묶고 결과 수, 빈 결과 안내, 초기화 버튼 제공 | 검색 결과가 없을 때 바로 조건을 되돌릴 수 있다. |
| 제작 단계 | 번호와 현재 단계 강조, 완료 단계의 돌아가기 유지 | 현재 위치와 이어질 단계를 구분한다. |
| 상품 입력 | 선택 항목 표시, 근거 입력 설명, 하단 고정 버튼 | 필요한 정보를 이해하고 스크롤 중에도 다음 행동을 찾을 수 있다. |
| 상단 이동 | 작업 도구 버튼을 상단으로 이동, `?view=tools` 직접 접근 제공 | 긴 화면 끝까지 내려가지 않아도 작업 도구에 접근한다. |

색상은 공통 테마 토큰을 사용한다. 새 스타일은 `.ic-page` 안에 한정했다. 공유 상품 컴포넌트의 정보와 수정 기능은 유지했다. 카드뉴스 코드, API 계약, 생성·승인 로직, DB 스키마는 변경하지 않았다.

## 실제 브라우저에서 확인한 항목

- 데스크톱 1450×1000: 작업 선택 두 영역, 포맷 미리보기, 상품 요약 세 카드, 단계 표시를 확인했다.
- 모바일 390×844: 작업 도구와 상품 선택 화면에 가로 넘침이 없었다. 상품 입력의 하단 버튼은 화면 안에 유지됐다.
- 라이트/다크 모드에서 상품 정보, 입력란, 단계, 버튼을 확인했다. 확인 후 라이트 모드로 돌렸다.
- 새 작업 이름이 없을 때 생성 불가 → 입력 후 생성 → 기존 작업 목록에 표시 → 주소로 다시 열기까지 확인했다. 만든 QA 작업은 휴지통으로 옮겼다.
- 포맷 검색 0건 → 필터 초기화 → 분류로 2건 표시 → 상세 펼치기 → 작업에 선택 상태 표시까지 확인했다.
- 체험 상품 선택 → 소구점 선택 단계로 이동 → 상품 선택 단계 복귀 시 상품 요약 유지까지 확인했다.

## 앞선 광고 소재 제작 화면 QA: 남은 개선사항

아래 항목은 별도 화면인 `/content/projects?platform=ad`의 이미지 소재·영상 소스 제작에서 발견했다. 이번 `/content/images` 스타일 수정으로 해결됐다고 보지 않는다.

| 우선순위 | 발견 내용과 근거 | 개선안 |
| --- | --- | --- |
| 높음 | 이미지 메시지·소구를 입력한 뒤 ‘단계별 광고 기획’에 들어갔다 목록으로 돌아오면 두 입력이 사라졌다. 브라우저 재현. | 초안 자동 보관과 복귀 시 복원, 저장 전 이탈 안내. |
| 높음 | 영상 두 장면에 화면 설명을 입력한 후 첫 대사를 고치면 첫 장면 설명이 지워졌다. 브라우저 재현. | 장면에 고정 ID를 부여하고 대사 편집과 화면 설명을 독립적으로 유지. |
| 높음 | 9:16·16:9는 공급자 요청 비율과 출력 비율이 다르며 `fit: contain`으로 맞춘다. 공급자가 요청 크기로 응답할 때 양옆 또는 위아래 흰 영역 합계가 면적의 15.625%가 되는 것을 단색 이미지로 재현했다. 실제 AI 응답 품질 검증은 아님. | 요청 비율과 출력 방식을 맞추거나, 잘림/확장 방식을 명확히 선택하게 개선. |
| 중간 | 이미지 비율을 1:1로 설정하고 이미 활성화된 이미지 탭을 다시 누르면 4:5로 초기화됐다. 브라우저 재현. | 현재 탭 재선택은 상태를 유지. |
| 중간 | 한 문단의 세 문장은 한 장면으로만 처리된다. 13줄 입력 시 생성이 막히고 장면 편집 영역이 사라진다. 브라우저 재현. | 자동 장면 나누기, 제한 초과 부분 표시, 편집 영역 유지. |
| 중간 | 내 광고·이미지 광고·단계별 광고 기획의 진입 경로와 제작 방식이 달라 처음 사용자가 어디서 시작해야 할지 판단하기 어렵다. 화면 비교 관찰. | 시작 화면에서 ‘소재 빠르게 만들기’와 ‘기획·검수하며 만들기’의 목적과 결과를 설명. |
| 중간 | 연속 생성은 브라우저가 다음 요청을 이어 보내므로 화면 이탈 시 다음 이미지가 시작되지 않는다. 코드 확인이며 연결 생성 재현은 미수행. | 백그라운드 작업 처리 또는 남은 작업의 중단·재개 상태를 명시. |
| 중간 | 완료 결과의 개별 수정 경로가 없고, 입력 변경 후 재제작하면 참고 이미지를 다시 올려야 한다. 코드 확인. | 결과 한 장 수정·재생성 및 참고 이미지 재사용. |

우선순위는 입력 손실 방지 → 출력 비율 일치 → 장면 편집 안정화 순으로 권장한다. 실제 AI 품질과 저장 안정성은 승인된 DEV 연결에서 별도 확인해야 한다.
