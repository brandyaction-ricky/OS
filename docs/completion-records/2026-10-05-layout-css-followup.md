## 구현

- 콘텐츠 화면별 전용 선택자를 보강하고 원고 공정, 숏폼 카드, 발행 필터와 최종 점검 빈 상태를 정렬했다.
- 카드뉴스 시안에 미리보기 제목·본문 필드를 추가하고 설정한 글자 수 제한을 넘으면 저장을 막는다. 기존 레코드는 기본 문구로 역호환한다.
- YouTube 연결과 접힌 서비스 설정 영역을 작동 상태 전용 패널로 변경했다.

- 회사 설정을 카드 그리드로 정리하고 지식 폴더 목록과 외부 관리자 링크의 모바일 넘침을 수정했다.
