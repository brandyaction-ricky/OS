## 범위

- 원고·스크립트, 숏폼 편집, 발행·업로드, 콘텐츠 자동화 최종 점검 화면의 전용 레이아웃을 보강한다.
- 카드뉴스 시안에서 제목과 본문을 직접 편집하고 미리보기와 저장 데이터에 반영한다.
- 작동 상태와 회사 설정의 기본 HTML처럼 보이던 영역을 공통 패널 체계로 정리한다.
- 변경 기록에서 선택 전 빈 상세 안내 카드를 제거한다.
- 기존 API·DB·권한·승인·발행 계약은 변경하지 않는다.

## 구현

- 콘텐츠 화면별 전용 선택자를 보강하고 원고 공정, 숏폼 카드, 발행 필터와 최종 점검 빈 상태를 정렬했다.
- 카드뉴스 시안에 미리보기 제목·본문 필드를 추가하고 설정한 글자 수 제한을 넘으면 저장을 막는다. 기존 레코드는 기본 문구로 역호환한다.
- YouTube 연결과 접힌 서비스 설정 영역을 작동 상태 전용 패널로 변경했다.
- 변경 기록은 상세 항목을 선택했을 때만 2열이 되고, 선택 전에는 목록을 전체 너비로 쓴다.
- 회사 설정을 카드 그리드로 정리하고 지식 폴더 목록과 외부 관리자 링크의 모바일 넘침을 수정했다.
