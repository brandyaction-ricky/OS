- 최신 main의 영상 길이·풀링형 원고·썸네일 프레임·매출 표시를 보존하면서 광고 제작과 카드뉴스 정본 추적을 통합했다. 별도 원본 작업 브랜치는 변경하지 않았다.

## 현재 검증 근거

- 통합 빌드 통과. lint 오류 0, 경고 22. 관련 검사 91개 통과.
- 로컬 자동 브라우저 2개는 Chromium 프로세스 시작 권한 오류로 실행되지 않았다. 실제 연결 브라우저에서 수동 검수 진행.
- 광고 5종 PNG 실제 출력·ZIP 다운로드. 모두 1080×1350, 각 미리보기와 ZIP 내부 PNG SHA-256 일치.
- 사진 업로드 전 미저장 입력 보존, 공통 사진 두 장 업로드 후 단일 선택, 본문 34자 제한 표시, 승인 전 출력 잠금 확인.
- 390px 모바일 가로 넘침 없음. 새로고침 후 5장 복원 확인.
- 회사 AI·DEV 저장소·실제 Mac 출력은 자격 증명과 검증 환경이 없어 미수행. mock 검증은 실제 생성 품질 검증을 대체하지 않는다.
