# 마이인 카드뉴스 썸네일 디자인 시안

## 범위와 완료 기준

- 광고 UI 작업 브랜치에서 독립 디자인 비교 화면을 추가한다.
- 캐릭터 중심, 보고서 중심, 질문 중심 3종을 같은 제목으로 비교한다.
- 원본 캐릭터와 공개 보고서 이미지를 보존하고, 1080×1350 PNG로 저장한다.
- 제목 편집, 디자인 선택, 피드 크기 비교, 새로고침 후 복원, 모바일 표시를 검증한다.
- 카드뉴스 생성기 및 다른 작업 브랜치의 공용 컴포넌트 수정은 범위에 포함하지 않는다.

## 확인한 기준과 자산

- BRANDYACTION 핵심 컨텍스트 v12 원문: 마이인의 대상과 문제 정의 확인.
- 마이인 캐릭터 정본 · 2026-11-24 v3 원문: 형태·비율·색상 보존 원칙 확인.
- 카드뉴스 정본 원문: 초안 상태임을 확인하고 표지의 가독성 원칙을 참고. 최신 승인 정본으로 간주하지 않음.
- 최신 컬러 가이드: 브랜드 블루 #2F65D9, 제목 #1E2430, 연한 배경 #EEF4FF.
- 최종 2D 캐릭터 원본: 투명 여백만 배치 계산에서 제외. 표정·색상·몸 비율 변경 없음.
- 보고서: 마이인 공식 홈페이지의 가상 인물 ‘마이니’ 공개 견본 첫 장. 공개 이미지 `https://www.myinlab.co.kr/images/home-cx/sample-cover-1117.jpg`를 사용. 고객의 실제 보고서가 아님.
- 보고서 점수나 차트는 재생성하지 않음. 하단 통계 문구는 썸네일에서 제외. 보라색 캐릭터가 견본의 효율형을 뜻하지 않음을 화면에 설명.
- 썸네일 제목은 디자인 비교용 초안이며 콘텐츠 승인 완료를 의미하지 않는다.

## 검증

수행:

- 로컬 HTTP 200, JavaScript 문법 검사 통과.
- 실제 브라우저 1450px 데스크톱 / 390px 모바일: 가로 넘침 없음.
- 3종 시각 검수, 240px 피드 보기, 선택 표시 및 저장 대상 전환 확인.
- 빈 제목 / 20자 초과 폭 제목의 설명과 저장 차단 확인.
- 제목 3줄과 선택 디자인이 새로고침 후 복원됨을 초기화 완료 뒤 재확인.
- 실제 다운로드 파일명을 한 건씩 확인한 PNG 3개 모두 1080×1350, SHA-256이 각 미리보기 PNG와 일치.
- `npm run verify`: 환경 검사, lint, typecheck 통과. 기존 lint 경고 유지.
- 전체 테스트: 1,945 통과, 10 건너뜀, 1 실패. 실패는 기존 `tests/myin-replaced-run-stop.test.mjs`의 `killTree` 테스트가 sandbox에서 `ps`를 실행할 수 없는 `spawnSync ps EPERM`이다. 변경된 썸네일 코드와 무관한 실행 환경 제약이며 성공으로 처리하지 않음.

미수행:

- `npm run verify`의 build 단계는 앞선 테스트 실패로 도달하지 못함.
- OS 카드뉴스 생성기 통합 / 앱 전체 E2E / DEV·운영 배포 검증: 독립 시안 범위이며 운영 기능은 변경하지 않음.
- 실제 광고 전환율, 게시 후 성과, 다른 브라우저 엔진: 미검증.
