# OS 개발 요청 · 제작 후 광고 디자인 편집과 Meta 세이프 존

**사용 흐름** · 이미지 광고 작업에서 카피를 승인한 시안 선택 → 디자인 편집 → 수정본 저장 → 수정본의 포맷·카피 승인 → 미리보기 확인 및 Mac 출력 → 최종 검수 → PNG / ZIP 다운로드.

## 무엇을 편집하는가

- **서체** · 포맷 고유 서체, 고딕, 명조, 손글씨, 간판체를 선택한다. 사용자가 입력한 제목·설명·버튼·브랜드 문구가 그대로 남는다.
- **카드 디자인** · 포맷 고유 구성, 프레임, 종이 카드를 선택한다. 옵션 간 차이는 실제 여백·테두리·카드 면에 나타나야 한다.
- **규격** · 피드 1:1·4:5, 스토리·릴스 9:16에서 선택한다. 가로 1080px와 1440px를 지원한다. 1440px 기준 결과는 각각 1440×1440, 1440×1800, 1440×2560이다.
- **이력** · 저장 시 원본과 연결된 편집본을 만든다. 브랜드·소구·카피·사진 및 기존 포맷 버전을 유지한다. 새 편집본은 최종 검수 완료 후 후속 비교 기준으로 선택할 수 있다.
- **적용 범위** · 이미지 광고 생성기의 일반 템플릿 12종과 제작 가능한 창고 포맷 5종. 참고용으로 보관한 타사 광고 원본은 참고자료다.

## 이미지의 보호 영역

게재 위치와 출력 해상도에서 안쪽으로 반올림한 픽셀 좌표를 산출한다. 위치와 해상도가 바뀌면 최종 캔버스에서 제목·본문·로고·CTA 등 핵심 요소가 보호 영역 안에 있도록 다시 배치한다. 가이드는 편집 화면의 레이어로 표시하며 결과 PNG에는 포함하지 않는다. 사진이 이미 합성된 자료라면 원본 속 글자·제품의 식별은 사람이 최종 게재 위치 미리보기에서 확인한다.

| 정적 이미지 게재 위치 | OS가 중요 요소를 두는 영역 |
|---|---|
| Facebook·Instagram 피드 1:1 / 4:5 | 위·아래·좌·우 각각 5%를 OS의 자체 제작 여백으로 둔다. |
| Facebook·Instagram 스토리 / 릴스 9:16 | 상단 14%, 좌우 각각 6%, 하단 40%를 비운다. Meta 가이드의 하단 35%보다 5%p 넓게 둔 OS 공통 직사각형이다. |

예를 들어 1080×1920에서는 좌측 65px·상단 269px에서 시작하는 950×883px가 핵심 영역이다. 여백 규칙은 한 곳(`lib/image-creative/placement.ts`)에서 버전 관리하고 편집 가이드와 출력에 함께 쓴다. 자동 게재 위치에서 한 장을 일괄 크롭해 쓰는 상황은 광고 관리자에서 위치별 미리보기를 추가 확인한다.

**근거** · Meta가 발행한 Stories/Reels 단일 이미지 광고 가이드에서 9:16 화면의 위 14%, 아래 35%, 좌우 6%를 주요 텍스트·로고 등에 비워 두라고 안내한다. 이번 확인에서 실시간 가이드는 로그인 화면을 반환해 공개 원문 보존본에서 수치를 확인했다. 피드 5%와 세로 하단 40%는 OS의 제작 기준이다. 확인일 2026-11-10. ## 인수 조건

1. 일반 프로젝트 시안에 글꼴·카드·규격 편집을 적용한다. 저장 전부터 실제 결과를 볼 수 있고 저장 후 재열기와 후속 테스트에서도 같은 디자인을 재현한다.
2. 새 시안과 기존 시안의 현재 내보내기에도 보호 영역이 적용된다. 편집 가이드 표시를 꺼도 실제 결과의 보호 영역을 유지한다.
3. 1:1·4:5·9:16, 1080·1440 출력에서 파일 크기와 주요 요소 좌표를 확인한다. 개별 PNG와 ZIP 속 같은 시안의 내용이 일치해야 한다.
4. 디자인 편집은 광고 등록·게시·집행 동작을 일으키지 않는다. 원본 및 이전 파일을 유지하고 재시도 시 중복 저장을 방지한다.
