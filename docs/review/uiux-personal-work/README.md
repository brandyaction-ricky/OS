# OS-12 · OS-18 · OS-19 검토 범위

C의 통합 코드 위에서 개인 홈(받은 일·검토/승인·요청한 일), 경영 보기 전환, 통합 알림, 수정 요청 서랍, 요청 요약을 추가합니다. 기존 주소와 개발 알림 API를 유지합니다. 업데이트 내역은 `/knowledge/development?tab=history`로 직접 열립니다.

알림 원본은 사용자 RLS로 다시 확인합니다. 권한이 없거나 보관된 원본은 제목과 미읽음 건수에서 제외됩니다. 일반 기록 API·버전 API·직접 DB 조회로 새 알림 메타데이터를 읽거나 조작할 수 없습니다. 새 알림은 공유 감사 스냅샷을 만들지 않습니다. 사람의 자기 행동은 자기에게 알리지 않습니다. 문서 검토 요청은 기존 관리자, 검토 완료는 문서 소유자에게 전달하며 권한 자체는 바꾸지 않습니다. 담당자가 지정된 업무의 배정·검토·승인, AI 작업 막힘, 개발 요청 상태 변경을 처리합니다. 개발 멘션은 기존 알림이 담당합니다.

화면 캡처는 사용자가 공유할 창/화면을 선택하고 미리보기를 확인한 후 등록할 때만 업로드됩니다. 미지원·취소 시 파일 첨부를 안내합니다. 기존 추가 개발 요청과 Markdown 첨부 흐름을 유지합니다.

데이터/API 변경은 `docs/openapi.yaml`에 기록했습니다. 알림과 요청 요약을 위한 추가 마이그레이션은 **파일만 작성했으며 적용하지 않았습니다**. 적용 전에는 새 알림을 연결 준비 중으로 표시하며 기존 알림과 기존 상태 변경은 유지합니다.

검증: 로컬 데모에서 전체 verify 및 브라우저 회귀 검사. 캡처는 실제 계정·업무가 없는 데모 화면이며 프로필을 가렸습니다. DEV 계정 기반 60초 이내 배지 갱신, 외부 협업자 실제 계정, 캡처 OS 선택창, 실제 첨부 업로드, pgTAP는 별도 검증이 필요합니다. G1 승인 정책·G2 외부 계정 정책은 확정하지 않았습니다. 운영 배포·운영 DB 변경·OS 동기화는 수행하지 않았습니다.
