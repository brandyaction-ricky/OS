# OS-16 · OS-11b 제작 현황과 화면 통합

우리 콘텐츠 한 개를 한 카드로 모으고 저장된 산출물에 따라 기획·원고·제목/썸네일·숏폼·발행 열로 분류합니다. 이 분류는 다음 작업 안내이며 승인 완료를 추정하지 않습니다. 원본 ID와 단계가 주소에 남고, 실제 원본을 찾지 못하면 다른 콘텐츠를 대신 선택하지 않습니다. 기존 원고 라이브러리·기획 도구·제작 자산·전체 승인 현황을 유지합니다. YouTube 채널 동의·해제는 작동 상태로 이동합니다. 실제 발행·승인 정책은 변경하지 않습니다.

회사 현황(성과 통합·목표·월간 보고서·주간 KPI), 매출/주문, 광고/전환, 일정/휴가를 탭으로 통합합니다. 모든 이전 주소는 해당 탭으로 이동하며 원본/기록 ID와 조회 조건을 보존합니다. 주제·경영지원·제목/썸네일·숏폼의 내부 탭도 주소로 공유할 수 있습니다. 전체 화면 h1은 메뉴 이름 하나이고 탭 제목은 h2로 표시합니다.

기존 주소 보존 원칙에 따라 이전 주소를 삭제하지 않고 리다이렉트를 제공합니다. 새 제작 현황만 /content/production을 사용합니다. 최종 메뉴 25개 중 Skill 임시 하위 메뉴 제거는 P2 OS-22 이후이며 현재 26개입니다. 신규 DB/API 계약·마이그레이션 없음. PR120 핫비디오 변경과 겹치는 주제 화면을 확인했고 해당 기능/서버 작업을 병합하지 않았습니다.

검증: verify(린트·타입·단위 447개·빌드) 통과, 전체 브라우저 54개 통과·1개 생략(DEV 자격 증명 없음), diff 검사 통과. 이전 주소/조회 보존, 하나의 h1, 단계 이동·새로고침·뒤로/앞으로가기, 없는 원본 차단, 이전 도구 유지, 채널 연결의 설정 위치를 확인했습니다. 다크·밝은 1440·390 캡처 12개는 프로필을 가린 로컬 데모입니다.

미수행: 인증 DEV 실제 데이터로 제작 저장·승인·렌더·업로드, 실제 OAuth 동의, 연결된 Preview 사용자 흐름. 외부 쓰기와 운영 반영은 하지 않았습니다. G1은 미정이며 현 승인 규칙을 보존합니다. OS 완료 기록은 로컬 보관·동기화 대기입니다.
