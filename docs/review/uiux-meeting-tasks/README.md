# OS-13 · OS-14 회의·업무 검토

회의 추출 결과를 결정·업무·미결·제외로 검수하고, 업무 담당자와 기한을 지정해야 확정할 수 있습니다. 실제 활성 구성원 ID를 저장하고 서버도 명시적 검수 업무의 담당·기한·회의 접근 권한을 확인합니다. 기존 입력 계약과 승인 정책은 유지합니다.

같은 날 유사 회의를 비교하고 새 초안을 기존 회의에 이어 쓸 수 있습니다. 기존 회의를 자동 삭제하거나 대량 병합하지 않습니다. 여러 레코드 저장은 트랜잭션이 아니므로 부분 실패를 안내하며, 재시도 시 저장된 부모·자식과 버전을 다시 확인합니다. 기존 부모 프로젝트와 회의 출처를 보존합니다.

담당 없는 업무는 분류 대기에 모으며 최대 20개에 담당·기한을 일괄 지정합니다. 기본 보기는 내 업무이고 완료 기준은 별도 필드입니다. 결정은 회의·결정의 출처 필터로 통합하며 이전 주소와 조회 매개변수를 보존합니다. 회의 단계 버튼은 해당 입력 영역으로 이동합니다.

검증: npm run verify 445개 통과(린트·타입·빌드 포함), 전체 Playwright 47개 통과·1개 생략(인증 DEV 계정 없음), git diff --check 통과. 다크·밝은 테마 1440·390 화면은 실제 계정·업무가 없는 로컬 데모이며 프로필을 가렸습니다.

미수행: 실제 DEV DB 저장·부분 실패 복구·동시 수정, 녹음 업로드·AI 추출 호출, 사용자 계정별 접근 확인. DEV 자격 증명과 승인된 연결 검증이 필요합니다. 운영·DB 마이그레이션·OS 동기화는 수행하지 않았습니다. 신규 마이그레이션 없음.
