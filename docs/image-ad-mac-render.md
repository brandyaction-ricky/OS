# OS 이미지 광고 · 영상 제작과 같은 AI와 제작 컴퓨터 사용

## 담당자가 사용하는 순서

1. OS의 ‘콘텐츠 제작 → 광고 → 이미지 광고’에서 저장한 목표·퍼널, 포맷, 후보 수, 사용할 사진을 보고 포맷을 승인한다.
2. 직접 입력, 구독 AI 또는 결과 가져오기로 카피 후보를 준비한다. 담당자가 각 장의 제목·본문·CTA를 보고 카피를 승인한다.
3. 게재 위치와 세이프 존을 포함한 시안 미리보기를 확인한다. ‘이미지를 출력할 컴퓨터’에서 공용 맥미니 또는 내 Mac을 고르고 미리보기 확인과 최종 출력을 요청한다.
4. 선택한 Mac이 요청을 받아 묶음 전체를 PNG로 출력·업로드한다. OS가 형식·규격·해시를 확인하면 실제 출력에서 만든 검수용 이미지를 연다.
5. 담당자가 모든 장을 확인하고 최종 검수를 완료한다. 개별 PNG·묶음 ZIP을 내려받거나, 검수한 시안을 다음 비교 기준으로 선택한다.

버튼별 동작과 재검수는 [이미지 광고 승인 순서](image-ad-approvals.md)에서 확인한다.

## 영상 기능에서 이어받는 범위

영상의 ‘내 AI’는 직원에게 연결된 구독 모델로 기획표를 만들며 모델 이름을 결과에 기록한다. 영상의 공용 제작 컴퓨터와 개인 컴퓨터는 기획표를 실제 파일로 만든다. 이미지 광고도 같은 역할을 사용한다. 모델을 특정 공급자나 모델 번호에 고정할 필요가 없다. 회사 크레딧을 쓰는 별도의 영상 GPT·음성 기능은 이미지 광고 작업에서 호출하지 않는다.

기준 사진 한 장과 카피 다섯 개가 있으면 Mac은 같은 사진으로 다섯 장을 만든다. 원본 사진 자체를 새로 만들 때는 이미지 생성 기능이 있는 직원 구독 AI가 원본을 생성해 프로젝트에 등록한다. 같은 파일을 다시 가져오기만 한 사례를 신규 이미지 생성 성공으로 기록하지 않는다.

## 인수 조건

- 공용 대상으로 요청한 묶음과 개인 대상으로 요청한 묶음을 각각 지정된 종류의 기기에서만 처리한다. 개인 요청은 요청자의 기기로 한정한다.
- 선택한 기기가 작업을 받기 전에는 대기 상태다. 다운로드할 실제 결과는 해당 기기가 올린 PNG다. 카피 승인, 미리보기 확인, Mac의 파일 출력 완료, 담당자의 최종 검수 완료를 각각 표시해야 한다.
- 재시도 때 이전 원본과 편집 이력을 보존한다. 다른 작업·다른 직원의 파일을 결과로 제출할 수 없어야 한다.
- 운영 인수는 검수 계정과 연결된 두 기기를 사용한다. 같은 입력을 양쪽에서 출력하고 해당 프로젝트에서 실제 PNG를 내려받아 규격·문구·사진·세이프 존을 확인한다.
