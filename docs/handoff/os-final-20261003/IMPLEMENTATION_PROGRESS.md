## S6 — 계정별 채널 연결

- 내 계정: 정보·테마·비밀번호 모달, YouTube/인스타/Threads 카드, 팀 공유, 테스터 요청·등록 표시, 모의 동작.
- 서버: 사람 전용 본인·팀 공유 권한, 관리자 해제, 비활성 소유자 차단, 암호화 Meta 토큰, 서명 OAuth state, 안전한 응답 필드.
- YouTube: 연결·업로드·발행 조건 승인에서 본인/공유 규칙 적용. 업로드 결과 재시도는 최초 연결 소유자를 보존한다. 기존 최종 검수·발행 조건 검사는 유지한다.
- 작동 상태: 계정별 연결 표. 전체 계정 목록은 관리자 전용이며 일반 직원은 본인·공유 계정만 본다. 모든 직원에게 비공유 계정 목록을 노출하는 변경은 안전 검토에서 거절되어 제한했다.
- 신규 마이그레이션은 **미적용**. YouTube 채널 유일 인덱스는 동시 중복 연결을 막기 위한 추가 항목이다. 기존 중복이 있으면 행을 고치지 않고 트랜잭션을 실패시킨다. 운영 적용 전 점검·승인이 필요하다.
- 로컬 확인: 내 계정 1440px 밝게/다크, 모의 Instagram 연결·공유·테스트, 390px 가로 넘침 없음. 비밀번호 입력·변경은 수행하지 않았다.
- 최종 전체 verify 483개 시험·린트·타입·빌드 통과. 관리자 목록 차단 및 토큰 비노출 시험 포함.
- 미검증: 실제 DB 적용/RLS·OAuth·테스터 알림 수신·토큰 갱신·실업로드. 상세 준비와 공식 출처는 `docs/META_CHANNEL_SETUP.md`.
