# 2026-10-05 페르소나 UI/UX QA 후속 수정

기준: 1,000명 합성 페르소나 QA 보고서의 네 권고 사항. 이 기록은 로컬 개발 작업 결과이며 운영 배포 기록이 아니다.

## 반영 범위

- 지식 문서 트리: 행 자체에 `treeitem` 의미를 부여하고 가상 스크롤 여백을 접근성 트리에서 제외했다. 방향키·Home/End·Enter/Space·Shift+F10 탐색을 추가하면서 기존 버튼과 드래그 작업을 유지했다.
- 확대 화면: 실효 213px·260px 폭에서 상단바를 두 줄로 배치해 검색, 가이드, 빠른 기록, 알림 버튼이 화면 밖으로 밀리지 않게 했다.
- 사용 가이드: 닫기 버튼의 조작 영역을 28×28px로 확대했다.
- 모바일 단계 탭: 공정 및 주제 단계에 좌우 스크롤 안내를 추가했다.

## 로컬 검증

- 린트·타입 검사 통과. 린트의 기존 `publication-settings-panel.tsx` 이미지 최적화 경고 1건은 이번 범위 밖이다.
- 최종 코드의 프로덕션 빌드 성공(운영 배포 아님).
- Playwright 전체 92개 중 첫 격리 포트 실행은 91개 통과·연결된 DEV/QA 계정 테스트 1개 건너뜀. 최종 코드 병렬 실행은 89개 통과·2개 추적 파일 기록 오류였고, 해당 2개는 단독 재실행에서 모두 통과했다.
- axe-core: 12개 경로 × 390/1280px, 24개 화면 모두 WCAG 2 A/AA·2.1 A/AA 위반 0건.
- 213px·260px 재현 폭에서 페이지 가로 넘침 없음. 단계 탭의 내부 스크롤과 안내 문구, 가이드 닫기 영역을 브라우저 테스트로 확인.
- `npm run verify`는 기존 마이그레이션 환경 목록 기대값(`development`만 예상, 현재 `production`도 기록됨) 관련 단위 테스트 7개 때문에 중단됐다. 전체 560개 중 553개 통과. 이번 UI 변경 파일과 무관하며 별도 정리가 필요하다.

## 미실시·남은 게이트

- 연결된 개발 계정으로 로그인하는 통합 E2E, 실제 150% 브라우저 확대 및 실기기 보조기술 검증은 미실시. 로컬 데모·동등한 CSS 실효 폭으로 확인했다.
- 운영 DB/API 변경, 마이그레이션, 운영 배포는 하지 않았다.
- 회사 OS 개발 관리 기록은 로컬 환경 이전 중 쓰기 연결이 없어 동기화 대기.
